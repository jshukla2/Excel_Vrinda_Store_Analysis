# Vrinda Store Annual Report – 2022

This project contains the Excel dashboard report for Vrinda Store for the year 2022.
The report analyzes customer behavior, sales performance, top states, order status, and sales channels.

## Key Insights

- Women (64%) purchased more than men (36%).
- Most orders were successfully Delivered (92%).
- Amazon and Flipkart contributed the highest order share.
- Maharashtra, Karnataka, and Uttar Pradesh were the top-performing states.
- Adults generated the highest number of orders among age groups.
